# chatbot.js

código de bot whatsapp reacriado em Typescript, divido em funções (Client e Events).

### Instruções de uso:

- **Instalar dependências do projeto:** `npm install` (descritas no package.json) - será criado uma pasta `node_module` com todas dependências.
- **Typescript para javascript**: as instruções de como o Typescript deve converter estão no arquivo `tsconfig.json` -- Quando convertido será criado uma pasta `dist` com os arquivos finais. **Comando:** `npx tsc`ou apenas `tsc` instalando typescript globalmente com `npm install -g typescript`

  **Documentação de terceiros**

- whatsapp-web.js - https://docs.wwebjs.dev/index.html // Conexão com whatsApp
- Expressjs - https://expressjs.com/ // Cria o servidor web local na porta 3000
